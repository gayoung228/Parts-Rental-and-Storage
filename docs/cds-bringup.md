# CDS 문 감지와 내부 LED

KY-018 계열 모듈의 S → PA0, + → 3.3V, - → GND로 연결합니다.
실제 보드의 핀 표기를 확인하세요. 외부 서보 전원 GND도 STM32와 공통 연결합니다.

새 펌웨어를 다운로드하고 115200 baud 디버그 터미널을 확인합니다.
약 0.5초마다 다음 로그가 출력됩니다. Wi-Fi 연결 대기 중에는 측정이 지연될 수 있습니다.

```text
[CDS] ADC=500 voltage=0.403V door=OPEN led=ON
```

ADC는 12비트 값(0~4095)이며 출력은 8회 측정 평균입니다.
전압 표시는 ADC 기준 전압 3.3V를 가정한 추정값입니다.

1. 센서를 가리지 않은 상태로 3~5초 동안 ADC 범위를 기록합니다.
2. 손이나 불투명한 덮개로 센서를 가리고 3~5초 동안 ADC 범위를 기록합니다.
3. 실제 보관함에 설치한 후 문 열림/닫힘 조건에서도 같은 측정을 합니다.

밝을 때 값이 증가하는지 감소하는지는 실제 측정으로 확인합니다.
실측값은 밝을 때 약 500, 가렸을 때 약 3800입니다.
ADC 1500 이하 → OPEN, 3000 이상 → CLOSED로 추정하며 3회 연속 확인 후 상태를 바꿉니다.
1500~3000 사이에서는 기존 상태를 유지합니다. 아직 확정하지 못한 시작 상태는 UNKNOWN입니다.
ADC 읽기 오류 또는 중간 값은 연속 확인 횟수를 초기화합니다.
설정은 `Core/Inc/door_sensor.h`에서 변경할 수 있습니다.
이 판정은 밝을 때 문이 열리고 어두울 때 문이 닫힌다는 설치 조건을 가정합니다.
내부 LED는 PB0의 HIGH 출력으로 켭니다. OPEN이면 ON, CLOSED 또는 시작 UNKNOWN이면 OFF입니다.
단일 LED는 직렬 저항을 사용하고, 별도 전원의 내부 조명은 적절한 구동 회로의 입력을 PB0에 연결하세요.
상태 변경 시 `[LED] State=ON/OFF`가 출력됩니다. 판정이 3회 연속 확인되어야 하므로 약 1~1.5초 후 전환됩니다.
중간 ADC 값에서는 기존 문 판정과 LED 상태를 유지합니다. ADC 읽기 오류 시에도 마지막 LED 상태를 유지합니다.
CDS가 내부 LED 빛을 직접 받으면 문을 닫아도 밝다고 판단할 수 있으므로 센서 위치를 조정하고 닫힌 상태의 값을 다시 확인하세요.
서보는 같은 카드의 승인된 재태그로 잠금/해제를 전환합니다.
LOCK 상태에서 OPEN이 지속되면 관리실 Arduino에 경보를 전달합니다. [관리실 경보 안내](management-alarm.md)를 따르세요.
보관함 잠금 상태를 DB에 저장하지 않습니다.
CDS ADC 값은 약 5초 간격으로 중계 서버를 통해 sql_client에 보내 cds_samples에 저장합니다.
카드 승인 대기 중에는 전송을 미룹니다. 설정·실행은 [DB 자동 저장 안내](db-auth.md)를 따르세요.
